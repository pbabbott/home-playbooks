# CrowdSec: HAProxy Firewall Bouncer

**Goal:** Install `crowdsec-firewall-bouncer` on the HAProxy LXC so known-bad IPs are dropped at iptables before reaching k8s. Decisions come from CrowdSec LAPI running in the prod k8s cluster.

**Dependency:** k8s LAPI must be deployed and accessible first. See `2026-06-11-crowdsec-k8s-lapi.md` (home-kubernetes repo).

---

## What changes

### `terraform/modules/haproxy/main.tf`

Add a second `terraform_data` resource (separate from `haproxy_guest`) that installs and configures the firewall bouncer. Keeping it separate means bouncer config changes don't re-provision HAProxy itself.

```hcl
resource "terraform_data" "crowdsec_bouncer" {
  depends_on = [proxmox_virtual_environment_container.haproxy_lxc]

  triggers_replace = [
    proxmox_virtual_environment_container.haproxy_lxc.id,
    var.crowdsec_lapi_url,
  ]

  provisioner "remote-exec" {
    inline = [
      "set -eux",
      "curl -s https://packagecloud.io/install/repositories/crowdsec/crowdsec/script.deb.sh | bash",
      "apt-get install -y crowdsec-firewall-bouncer-iptables",
      # Write bouncer config
      "sed -i 's|api_url:.*|api_url: ${var.crowdsec_lapi_url}|' /etc/crowdsec/bouncers/crowdsec-firewall-bouncer.yaml",
      "sed -i 's|api_key:.*|api_key: ${var.crowdsec_bouncer_api_key}|' /etc/crowdsec/bouncers/crowdsec-firewall-bouncer.yaml",
      "systemctl enable --now crowdsec-firewall-bouncer",
      "systemctl is-active crowdsec-firewall-bouncer",
    ]
    connection {
      type        = local.ssh_haproxy.type
      user        = local.ssh_haproxy.user
      private_key = local.ssh_haproxy.private_key
      host        = local.ssh_haproxy.host
      timeout     = local.ssh_haproxy.timeout
    }
  }
}
```

### New variables (root `variables.tf` or passed into module)

```hcl
variable "crowdsec_lapi_url" {
  description = "CrowdSec LAPI URL reachable from HAProxy LXC (e.g. http://192.168.6.25:32080)"
  type        = string
}

variable "crowdsec_bouncer_api_key" {
  description = "API key generated by cscli bouncers add haproxy-bouncer in k8s"
  type        = string
  sensitive   = true
}
```

### `terraform.tfvars.example`

```
crowdsec_lapi_url        = "http://<k8s-node-ip>:<nodeport>"
crowdsec_bouncer_api_key = "your-bouncer-api-key"
```

---

## No haproxy.cfg changes needed

The firewall bouncer operates at iptables level — it does not touch HAProxy config. Banned IPs are dropped by the kernel before HAProxy sees the connection.

---

## Verify after apply

```bash
# On HAProxy LXC
systemctl status crowdsec-firewall-bouncer
iptables -L crowdsec-blacklists -n   # should exist, may be empty initially

# From workstation — confirm LAPI connection
ssh root@192.168.6.28 "crowdsec-firewall-bouncer -c /etc/crowdsec/bouncers/crowdsec-firewall-bouncer.yaml -t"
```

## Prerequisites checklist

- [ ] CrowdSec LAPI deployed in k8s and accessible at `192.168.6.x:<nodeport>`
- [ ] Bouncer API key generated (`cscli bouncers add haproxy-bouncer`)
- [ ] `crowdsec_lapi_url` and `crowdsec_bouncer_api_key` added to `terraform.tfvars`
